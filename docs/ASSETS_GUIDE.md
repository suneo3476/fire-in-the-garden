# 素材配置ガイド

## 📦 素材の受け取りと配置方法

### ステップ1: 素材をassetsフォルダに配置

クリエイターから受け取った素材を、適切なフォルダに配置してください：

```
assets/
├── characters/       # 立ち絵PNG/JPEG
│   ├── player_default.png
│   ├── police_default.png
│   ├── detective_default.png
│   └── ...
├── backgrounds/      # 背景画像
│   ├── start_screen.png
│   ├── garden_day.png
│   └── ...
├── ui/              # UI素材（証拠品画像、ボタンなど）
│   ├── evidence_blueprint.png
│   ├── button_start.png
│   └── ...
├── bgm/             # BGM（MP3推奨）
│   ├── title.mp3
│   └── ...
└── sfx/             # 効果音
    ├── bark.mp3
    └── ...
```

**ファイル名は自由ですが、後でマッピングファイルで指定するので覚えておいてください。**

---

### ステップ2: プレビューツールで確認

```bash
# プロジェクトルートで
python -m http.server 8000

# ブラウザで開く
# http://localhost:8000/tools/preview.html
```

または、直接HTMLファイルを開いても動作します：
```bash
open tools/preview.html
```

---

### ステップ3: 素材を割り当てる

#### 方法A: プレビューツールで割り当て（推奨）
1. `preview.html` を開く
2. タブで目的のカテゴリを選択
3. 素材をドラッグ&ドロップエリアにドロップ
4. プレビュー表示を確認
5. 「保存」ボタンで `assets-mapping-updated.json` をダウンロード
6. 元の `src/domain/assets-mapping.json` を上書き

#### 方法B: JSONファイルを直接編集
`src/domain/assets-mapping.json` を開いて、`filePath` を編集：

```json
{
  "characters": {
    "police_default": {
      "name": "警察（デフォルト）",
      "filePath": "assets/characters/police_standing.png",  // ← ここを変更
      "description": "警察の立ち絵（デフォルト表情）",
      "status": "配置済み"  // ← 配置したら「配置済み」に変更
    }
  }
}
```

## 🔊 BGM/効果音の入手方法

### DOVA-SYNDROME から無料で入手
https://dova-s.jp/

1. サイトにアクセス
2. ジャンル/雰囲気で検索（例: 緊張感、ミステリー、ピアノ）
3. 気に入った曲を試聴
4. ダウンロード（会員登録不要）
5. `assets/bgm/` または `assets/sfx/` に配置

**クレジット表記**: 不要（あると嬉しい程度）
**商用利用**: OK

## 💡 Tips

### 画像サイズの推奨
- **立ち絵**: 縦長（例: 1000x2000px）、PNG推奨（透過対応）
- **背景**: スマホ縦画面想定（例: 1080x1920px）
- **証拠品**: 正方形または横長（例: 512x512px）
- **UI素材**: 用途に応じて（ボタンは小さめ、テキストボックスは横長）

### ファイル形式
- **画像**: PNG（透過が必要な場合）、JPEG（背景など）
- **音声**: MP3（互換性が高い）、OGG（ファイルサイズ小）

### 命名規則
特に決まりはありませんが、分かりやすい名前を推奨：
- `character_name_emotion.png`（例: `detective_surprised.png`）
- `bg_location_time.png`（例: `bg_garden_night.png`）
- `evidence_item.png`（例: `evidence_knife.png`）

## ❓ トラブルシューティング

### プレビューツールで画像が表示されない
- ファイルパスが正しいか確認
- 画像ファイルが実際に存在するか確認
- ブラウザのコンソールでエラーを確認

### 素材の差し替えたい
1. `assets/` 内のファイルを差し替え
2. `assets-mapping.json` の `filePath` を更新（必要なら）
3. プレビューツールで確認
