# プロトタイプ起動ガイド

## 🚀 プロトタイプを動かす

### 方法1: ローカルサーバーで起動（推奨）

```bash
# プロジェクトルートで
cd /path/to/fire-in-the-garden

# Pythonのローカルサーバーを起動
python3 -m http.server 8000

# または Python 2 の場合
python -m SimpleHTTPServer 8000
```

ブラウザで開く：
```
http://localhost:8000
```

### 方法2: 直接HTMLを開く

ブラウザの制限（CORS）により、一部機能が動作しない可能性がありますが、基本的な動作確認は可能です：

```bash
open index.html
```

## 📝 開発メモ

### Monogatari構文メモ

```javascript
// セリフ
'character セリフテキスト'

// 改行
'{{br}}'

// キャラクター表示/非表示
'show character <id> <expression> at <position>'
'hide character <id>'

// 背景
'scene <id> with <transition>'

// 音楽
'play music <id>'
'stop music <id>'

// ジャンプ
'jump <label>'

// 選択肢
{
    'Choice': {
        'Dialog': '質問テキスト',
        'Option1': {
            'Text': '選択肢1',
            'Do': 'jump Label1',
            'Condition': function() { return true; }
        }
    }
}

// フラグ設定
{
    'Function': {
        'Apply': function() {
            this.storage.flags.flag_name = true;
        },
        'Reverse': function() {
            this.storage.flags.flag_name = false;
        }
    }
}
```

## 💡 Tips

### 素材がなくてもテスト可能
素材がなくても、テキストとシステムの動作確認は可能です。
プレースホルダー画像（単色の画像）を作成すると、より実感が湧きます。

### ブラウザのリロードで即反映
コード（js/script.js等）を変更したら、ブラウザをリロード（Cmd+R / Ctrl+R）するだけで反映されます。

### コンソールでデバッグ
F12キーでデベロッパーツールを開き、Consoleタブでエラーやログを確認できます。

## ❓ トラブルシューティング

### 画面が真っ白
→ ブラウザのコンソールを確認。JavaScriptエラーがないかチェック

### キャラクターが表示されない
→ 正常（素材未配置のため）。セリフは表示されればOK

### 選択肢が出ない
→ フラグの条件を確認。全てfalseだと選択肢が表示されない

### CORS エラー
→ ローカルサーバー（http.server）を使用してください
